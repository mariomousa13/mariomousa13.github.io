Testing mobility across 5G access gateways.

Design and implementation of mobility tests between Access Gateway Functions and the 5G Core.

Bachelor's Thesis · 2025 Universidad Politécnica de Madrid 5G Networks
01 / PROJECT FOCUS

Validating session mobility in a 5G testbed.

This thesis designed and implemented a functional test environment for handover between Access Gateway Functions (AGFs), software components used to connect access networks with a 5G Core.

The project focused on developing and validating mobility mechanisms between Access Gateway Functions (AGFs) connected to a 5G Core. By enabling active sessions to be transferred between gateways, the proposed approach supports more efficient resource utilization and creates opportunities for energy savings during periods of low network traffic.

02 / ENGINEERING WORK

Software, coordination and observability.

The project extended an Access Gateway Function with mobility capabilities and introduced a central controller to coordinate the handover process.

The controller combined registration and coordination services with a web interface designed for monitoring and operation.

03 / VALIDATION

Testing connectivity and handover behavior.

The test scenarios covered connectivity, signaling exchange, dynamic IP reassignment and session transfer between AGFs.

Traffic and packet-analysis tools were used to observe system behavior during functional validation.

This public overview focuses on the project's engineering objectives and validation approach. It does not include deployment addresses, credentials or internal configurations.
