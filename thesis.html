Orchestrating cybersecurity analytical models.

Design and Development of an Orchestration System for Cybersecurity Engineering Models

Master's Thesis · 2026Universidad Politécnica de MadridECYSAP-EYE
01 / Research question

How can separate analytical models work together?

Cybersecurity analysis can involve models that consume different inputs and produce different kinds of results. Using these models together requires a shared way to describe dependencies, coordinate execution and inspect outcomes.

This thesis addresses that coordination problem through a system for defining, executing and supervising analytical pipelines.

02 / Engineering contributions

A common workflow for complex analysis.

The work represents pipelines as directed acyclic graphs, making model order and dependencies explicit. It combines a user interface with backend services, workflow orchestration and asynchronous communication.

DefineCoordinateMonitorInspect results

The implementation supports pipeline design, execution control, status monitoring and results visualization. My contributions included dynamic workflow generation, dependency management and propagation of model results.

03 / Validation

Testing the complete functional flow.

The thesis reports two validation use cases: one using ECYSAP-EYE analytical models and another involving models related to MITRE ENGAGE. These exercises checked the workflow from pipeline definition through execution and results visualization, including component interconnection.

This is evidence of functional validation within the thesis scope. It does not establish production readiness, performance improvements or operational security guarantees.
